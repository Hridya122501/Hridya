## Recent Cybersecurity News
Recently, I came across news about the OpenCode Console breach, which may have exposed API keys from OpenAI, Anthropic, and Google. On October 16, OpenCode’s legacy system was breached, exposing third-party API keys for OpenAI, Anthropic, and Google. Impacting roughly 1.4% of Console users, the attack led to unauthorized billing spikes up to $1,700. OpenCode linked the credential theft to a large-scale model distillation attack, prompting urgent warnings for users to immediately revoke, rotate, and cap their keys.
